# Лендинг ЖК «Кислород» (Партикл, Астрахань)

Каркас и анимации — по разбору «Город-парк» (`Сайт ЖК — шаблон по мотивам Город-парк/DESIGN-SYSTEM.md`), бренд — руководство Партикл из Figma.

Превью для клиента и телефонов (GitHub Pages): https://kokosovna89-netizen.github.io/kislorod-landing/
Репозиторий: https://github.com/kokosovna89-netizen/kislorod-landing (публичный — только файлы сайта; `assets/src` и старые картинки исключены в `.gitignore`)
Обновить превью: закоммитить правки и `git push` — сайт обновится через 1–2 минуты. После правок CSS/JS поднять `?v=` в index.html.
Перед запуском на боевом домене: убрать `<meta name="robots" content="noindex, nofollow">` и отключить копию на GitHub Pages.

Рабочее превью в Claude: https://claude.ai/artifact/WuZuZaaAoZiGTXi9ZStDMr (приватное)

## Состав
- `index.html` — страница целиком (боевая версия, с подключением Marquiz)
- `assets/css/style.css` — токены бренда в `:root`, все компоненты
- `assets/js/main.js` — интерфейс и движение (GSAP + ScrollTrigger + SplitText с cdnjs, Lenis с unpkg)
- `assets/img/` — рендеры (сжаты до 1600–2400 px), планировки, отделка, схема района, логотипы
- `assets/src/` — исходники, скачанные с kislorod-astrahan.ru

Деплой: залить папку целиком на хостинг, сборка не нужна.

## Заявки
Все кнопки — ссылки на квиз Marquiz `6a0db6398b7a3c0019ec16cb`. На боевом домене загружается скрипт Marquiz, и квиз открывается поверх страницы. Без скрипта (например, в превью) кнопка открывает mrqz.me в новой вкладке. Своих форм на сайте нет, персональные данные собирает только Marquiz.

## Бренд
- Палитра брендбука: #FFFFFF, #EAEAEA, #000000, #1D1D1B, растяжка #8E8E8E → #1D1D1B.
- Фирменные цвета дома 2 из брендбука: `--clay: #DBB2A1` (плашки первого экрана и финала), `--blush: #E8D6CD` (фон «Условий покупки»). `--clay-deep: #A86F5A` — тот же тон темнее для мини-знаков и наведения. Красный #D10721 (дополнительный цвет) заведён в `--red`, но сейчас не используется.
- Первый экран повторяет композицию «Город-парка»: дневной рендер слева на всю высоту, справа плашка #DBB2A1 с диагональным краем знака. Окно кадра считает `fitHero()` в main.js: средняя и правая башни всегда целиком, край кадра не режет левую. Если меняете рендер, пересчитайте доли L/PAIR/C.
- Шрифт заголовков по брендбуку — **Muller**. Веб-файлов нет, поэтому сейчас стоит Montserrat. Когда пришлют woff2, добавьте `@font-face { font-family: "Muller"; ... }` — стек `--f-display` уже начинается с Muller.
- Маска раскрытия двора и паттерн собраны из знака Партикл (контур взят из SVG-логотипа).

## Проверить перед запуском
1. **Детский центр (ул. Куликова, 65В)** поставлен на схему по пересчёту координат OSM — сверьте точку.
2. **Время в пути** (5/7/8/10/12 мин пешком, 5 мин на авто) — расчёт по прямой с поправкой на маршрут. Уточните по Яндекс Картам.
3. **Отделка** — отдельный блок убран (правки 19.11). В планировках выделенная плашка «Отделка — Предчистовая отделка или ремонт» (формулировка клиента, 19.11).
3а. **Акцентный цвет** — клиент выбрал #DED9D5 (19.11, вариант 3 из `../Цвет — варианты`): `--clay: #DED9D5`, `--blush: #EEEBE9`, `--clay-deep: #8A817A`. Прежний #DBB2A1 из брендбука больше не используется.

Правки 19.11: убраны манифест (текст перенесён на экран раскрытия двора), блок «Отделка», финальный блок перед футером; добавлена липкая кнопка квиза (телефон — нижняя панель, компьютер — кнопка справа внизу).
4. Факт «на кровле паркинга — спортивная площадка» взят с рендера 14.jpg.
5. **Метрика**: в `KS_CONFIG.metrikaId` стоит `null`. Чтобы включить, впишите 109588373 (счётчик текущего сайта) или новый номер и добавьте код счётчика в `<head>`.
6. Ставки и дисклеймер ипотеки «до конца ноября» — актуализировать при смене акций.
